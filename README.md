### 🕹️ ABOUT PLAYER 1

Halo! Saya **Tan Heradhe Rat Djendra** (TanDjendra), pelajar & developer dari **MAN 3 Banyumas** (Angkatan 2023). Saya berfokus pada pengembangan **aplikasi web interaktif**, **otomasi bot 24/7**, **pengolahan media (Canvas/GIF)**, dan integrasi **Generative AI**.

- 🔭 **Proyek Terbaru:** [Auto-Menfess Instagram Bot](https://github.com/TanDjendra/Menfess-Auto-Generate-Post-Instagram) (Canvas PNG/GIF + Gemini AI + Instagram Graph API).
- 🎨 **Proyek Portofolio:** [TanDjendra Cyber-Arcade](https://github.com/TanDjendra) (Next.js 16, React 19, & 100% Synthesized Web Audio API).
- ⚡ **Eksplorasi:** Node.js, Next.js, Firebase Realtime Database, Gemini API, & Canvas Art.
- 🎯 **Prinsip Koding:** *Visuals First, Fast Loading, & Interactive Micro-Animations!*
